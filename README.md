# 我家的小倉庫

家裡庫存追蹤器，給手機瀏覽器用的單檔網頁 app（可以加到主畫面）。

## 功能（v1.7 單機版）

- 首頁依分類分區，每個物品用燈號標示狀態：
  - 🟢 充足：數量 ≥ 紅線 + 2
  - 🟡 快用完：數量 = 紅線 + 1
  - 🔴 待買：數量 ≤ 紅線，會自動加入待買清單，補到超過紅線才移出
- 兩種記錄方式：
  - **簡單計數**：按「＋ 入庫」或「− 用掉」
  - **使用中／備品**：按「開封」「用完」「補貨」，同一時間最多一包在用。紅線看的是備品數量
- 補貨時選 +1 / +2 / +3 / 自訂，按確認才會記錄
- 每次操作後 5 秒內可以按「復原」
- 每個物品都保留完整的歷史紀錄；切換記錄方式時，會先確認數量怎麼帶過去
- 使用速度：
  - 消耗估算：至少涵蓋 7 天、有 3 筆「用掉」紀錄才顯示
  - 一包用多久：至少 1 包從「開封」記到「用完」才顯示
  - 購買頻率：至少 2 天有補貨紀錄才顯示
  - 資料不夠時顯示「累積資料中」
- 待買清單可以一鍵分享到 LINE
- 新手介紹（v1.7）：7 張圖卡，第一次打開自動出現，之後可以從首頁右上角「？」或設定再打開
- 盤點校正：直接改成實際數量，不算消耗
- 分類可以自訂，有 13 種插圖可選（v1.4 新增冰箱、罐頭零食）
- 可以匯出／匯入 JSON 備份
- 新增物品後可以「繼續下一個」，保留分類、存放位置、用途和記錄方式（v1.5）
- 首頁可以依分類篩選，也能和狀態篩選一起用
- 沒有日常物品的分類不顯示在首頁和篩選列（v1.6），新增頁和設定裡照樣看得到
- **緊急備品**（v1.1）：和分類不衝突；和日常分開記數量，各有自己的目標和紅線
  - 新增物品時選「用途」：日常用品／日常用品，緊急包也備一份／只放緊急包（從緊急分頁新增時只有後兩個）
  - 有效數量 = 還沒過期的＋沒標效期的
  - 有效數量 ≤ 紅線，或有 30 天內到期／已過期要換新時，進待買清單
  - 「調用到日常」不算消耗
  - 每 6 個月提醒做一次檢查
- **有效期限**（v1.1）：補貨時可以選填，每一包的效期都可以不同，新補的不會蓋掉舊的
  - 新增物品時也可以直接填（v1.5），日常和緊急包各一組
  - 用掉、開封時會先扣最早到期的
  - 過期的日常品在按「丟棄」之前還算在庫存裡
- **開封提醒**（v1.1）：卡片顯示「已開封 X 天」
  - 新增時可以填開封日期（v1.5）
  - 開封後期限分三種：包裝標示、個人提醒（標明不是包裝建議）、未設定

資料目前存在手機瀏覽器的 localStorage。之後接上 Firebase 讓家人共用時，只需要替換 `index.html` 裡的資料層（`LocalAdapter`）。

## 部署（GitHub Pages）

1. 到 repo 的 Settings → Pages
2. Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾 `/ (root)`，按 Save
3. 等 1～2 分鐘，網址會是 `https://<帳號>.github.io/groceries/`
4. 用手機打開網址：
   - iPhone：Safari 分享 →「加入主畫面」
   - Android：Chrome 選單 →「加到主畫面」
