# v1.7 測試清單

**這版改了什麼**：新增「新手介紹」，共 7 張圖卡。
- 可以左右滑動，也可以按「上一張／下一張」
- 右上角 ✕ 隨時可以關閉，最後一張按「開始使用」也會關閉
- **第一次打開時自動出現**，看過或關掉之後就不會再自動出現
  - 「看過了沒」記在這支手機上
- **再打開的方法**：首頁右上角的「？」，或設定最上面的「使用說明 → 再看一次」
- 圖卡上半部用的是 app 裡真的元件，例如燈號、按鈕、效期標籤、插圖
  - 這些元件只能看，按了不會動到資料

**資料結構沒變。**

**電腦上已經自動測過**（`node tests/e2e.js`，86 項）：
- 第一次自動出現、一共 7 張、每張都有圖示
- 下一張、左右滑動、圓點跟著移動
- 最後一張是「開始使用」
- ✕、Esc、開始使用都能關閉
- 關掉後不會再自動出現
- 從「？」和設定都能再打開
- 圖卡裡的按鈕不會動到資料
- 之前所有功能

**怎麼用**：每一項寫的是「操作 → 應該看到什麼」。標 📱 的是只有手機才能確認的事。
