# v1.3 測試清單

> ✅ 2026-10-31 手機實測全部通過

**這版改了什麼**：從「緊急」分頁按「新增」時，用途只剩兩個選項：
- 🏠＋🆘 日常用品，緊急包也備一份
- 🆘 只放緊急包（預設）

底部「新增」和「編輯資料」還是三個選項，因為從這兩個地方新增日常用品，或把物品改回日常用品，都需要「日常用品」這個選項。

**只改了表單，資料結構沒變。**

**電腦上已經自動測過**（`node tests/e2e.js`，28 項）：
- 三個入口各自顯示幾個選項
- 預設選在哪一個
- 存成的資料都正確
- 原有功能（用掉、復原、補貨確認或取消、調用到日常）都正常

**怎麼用**：每一項寫的是「操作 → 應該看到什麼」。標 📱 的是只有手機才能確認的事。
