# v1.5 測試清單

**這版改了什麼**：新增物品時可以順手填完，不用建好後再去物品頁補。
1. **新增時填效期**：數量下面多了「有效期限（選填）」，可以選不填／全部同一個／每個不一樣。
   - 使用中／備品：列出「使用中那瓶」和每一瓶備品
   - 緊急包：另外一組效期
   - 數量是 0 時不會出現
2. **新增時填開封日期**：選「有，使用中」時，多一欄「什麼時候開封的」，預設今天。
3. **「新增，繼續下一個」**：新增後留在新增頁，保留分類、存放位置、用途和記錄方式。

另外，補貨面板和新增表單現在共用同一個效期元件，操作方式一樣。

**資料結構沒變**：效期一樣存成批次。

**電腦上已經自動測過**（`node tests/e2e.js`，60 項）：
- 效期欄位的顯示與隱藏
- 每個不一樣、自動帶入下一欄
- 存成的批次正確
- 使用中那瓶的效期
- 開封日期：未來日期會擋下、已開封天數正確
- 緊急包的效期
- 繼續下一個：保留哪些設定、清空哪些欄位
- 補貨面板的效期
- 之前所有功能

**怎麼用**：每一項寫的是「操作 → 應該看到什麼」。標 📱 的是只有手機才能確認的事。
