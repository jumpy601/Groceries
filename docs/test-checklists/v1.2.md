# v1.2 測試清單

**這版改了什麼**：新增／編輯物品時，原本的「這也是緊急備品」和「只放在緊急包」兩個勾選框，改成一題「用途」三選一：
- 🏠 日常用品
- 🏠＋🆘 日常用品，緊急包也備一份
- 🆘 只放緊急包

緊急包的欄位也改名為「緊急包的數量：目標存量／紅線／目前數量」。

**只改了表單，資料結構沒變**，舊資料不需要轉換。

**電腦上已經自動測過**（`node tests/e2e.js`，26 項）：
- 三種用途存成的資料都正確
- 從「新增」和從「緊急」分頁進來的預設選項不同
- 編輯時正確帶入目前的用途
- 緊急包或日常還有庫存時，不能改掉用途，並會顯示提示
- 用掉、復原、補貨確認或取消、調用到日常都正常

**怎麼用**：照順序做，每一項寫的是「操作 → 應該看到什麼」。有不一樣的地方，截圖並告訴我是第幾項。標 📱 的是只有手機才能確認的事。
