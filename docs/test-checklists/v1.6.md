# v1.6 測試清單

> ✅ 2026-10-31 手機實測全部通過

**這版改了什麼**：首頁隱藏沒有物品的分類（做法 A），上方的分類篩選列也一起隱藏。
- 「空」的意思是：這個分類裡**沒有首頁會出現的日常物品**。只有「只放緊急包」的物品，或只有封存的物品，也算空。
- 不再出現「這個分類還沒有物品」的區塊。
- **不受影響的地方**：新增／編輯物品的分類選項、設定裡的分類列表、緊急分頁，這些地方都照常列出全部分類。
- 分類放進物品後，會自動出現在首頁；物品都移走或封存後，又會自動隱藏。

**資料結構沒變**，只改了首頁的顯示。

**電腦上已經自動測過**（`node tests/e2e.js`，71 項）：
- 空分類不出現在首頁和篩選列
- 只有「只放緊急包」物品的分類也算空
- 新增頁、設定仍列出空分類
- 放進物品後出現、封存後消失
- 正在篩選的分類變空時，自動回到「全部」
- 之前所有功能

**怎麼用**：每一項寫的是「操作 → 應該看到什麼」。標 📱 的是只有手機才能確認的事。

## B. 隱藏空分類

- [ ] **B1** 首頁**沒有**任何「這個分類還沒有物品」的區塊；沒有日常物品的分類整個不見
- [ ] **B2** 上方分類篩選列只有首頁看得到的分類
- [ ] **B3** 設定 →「新增分類」→ 建一個「測試-空分類」→ 回首頁 → **看不到**它，篩選列也沒有
- [ ] **B4** 底部「新增」→ 分類選項裡**看得到**「測試-空分類」，可以選
- [ ] **B5** 在「測試-空分類」新增「測試-物品」，數量 1 → 回首頁 → 出現「測試-空分類」區塊，篩選列也有
- [ ] **B6** 篩選列點「測試-空分類」→ 只顯示這一區 → 把測試-物品封存 → 回首頁 → 該分類消失，篩選回到「全部」
- [ ] **B7** 如果有「只放緊急包」的物品（例如乾燥飯）所在的分類沒有其他日常物品 → 首頁看不到這個分類，但「緊急」分頁照常看得到那個物品

## 測完清除測試資料

1. 測試-物品：設定 →「已封存的物品」→ 按垃圾桶永久刪除。
2. 測試-空分類：設定 → 分類列表 → 鉛筆 →「刪除這個分類」。
