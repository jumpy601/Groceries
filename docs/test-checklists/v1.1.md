# v1.1 測試清單

**這版改了什麼**：分類篩選、緊急備品（含只放緊急包、半年檢查）、效期批次、開封天數與開封後期限、舊資料自動轉換。

**電腦上已經自動測過**：
- 燈號、待買清單、「建議買」的計算規則
- 先扣最早到期的、調用不算消耗、復原會還原批次
- 舊資料轉換
- 隨機操作 300 步後數字仍然對得上

所以這份清單著重在**只有你的手機能確認的事**：
- 版本有沒有更新到
- 你的真實資料是否完好
- iPhone 的日期選擇器、分享選單
- 畫面好不好讀

**怎麼用**：照順序做，每一項寫的是「操作 → 應該看到什麼」。有不一樣的地方，截圖並告訴我是第幾項。

測試時請新增**「測試-」開頭的物品**，不要動到真實資料。最後一節有清除方法。

## 測完清除測試資料

每個「測試-」物品：物品頁 →「封存」→ 設定 →「已封存的物品」→ 垃圾桶「永久刪除」。

測試-水的緊急還有庫存時不能取消緊急備品，但可以直接封存、刪除。
